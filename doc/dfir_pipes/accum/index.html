Shared accumulator state machinery (fold/reduce/sort) used by both pull and push accumulate combinators. Shared accumulator state machinery used by both the pull-based and push-based Accumulate combinators (crate::pull::Accumulate and crate::push::Accumulate).

The AccumState trait defines how items are accumulated and how the accumulated state is drained into an iterator on finalization. Each struct here encapsulates the accumulation logic and drain behavior for a specific operator (fold, reduce, sort), in both owned and borrowed modes.
