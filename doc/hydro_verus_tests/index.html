Test fixtures for Verus-checked proofs of algebraic properties (verus_proof_commutative_fold! / verus_proof_commutative_map!).

The flows in this crate are never executed; they exist so that the proof obligations generated at their q!(...) call sites are verified (or rejected) by Verus. Run:

cargo verus verify -p hydro_verus_tests --features verus

The accepted module must verify. Each module under rejected is gated behind a reject_* cargo feature and contains a bogus commutativity annotation that Verus must refuse to verify; the verus_rejects test harness enables them one at a time and asserts that verification fails.
