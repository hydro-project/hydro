pub fn toolchain_fingerprint(rustflags: &str) -> String
Expand description

Fingerprint of the compilation environment a child build runs under: the rustflags (in any stable encoding) and the compiler’s verbose version.

Cargo keys the filenames of rlibs on both of these, so different fingerprints never collide in the shared deps/ and can be cached side by side. It strips that key from dylib filenames unless __CARGO_DEFAULT_LIB_METADATA is set, so without that variable the trybuild dylib bakes this fingerprint into its target name instead (see dylib_lib_name).
