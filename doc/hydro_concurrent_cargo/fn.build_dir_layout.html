pub fn build_dir_layout() -> BuildDirLayout
Expand description

The BuildDirLayout used by the toolchain that compiled this crate.

The runtime cargo invocations coordinated by this crate use the same toolchain (rustup pins the toolchain for the whole process tree), so the compile-time verdict matches the layout of the builds we coordinate; switching toolchains recompiles this crate and re-runs the detection.
