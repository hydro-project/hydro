pub fn set_dylib_lib_name(project_dir: &Path, rustflags: &str)
Expand description

Point the project’s dylib manifest at the dylib_lib_name for rustflags.

Dylib builds call this first thing in their run_prebuild build_fn, i.e. under the exclusive prebuild lock, once no in-flight final build links the old name. It takes lock_project so a concurrent manifest regeneration cannot read the old name and write it back over the new one.
