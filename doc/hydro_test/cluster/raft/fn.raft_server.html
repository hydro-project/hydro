The unified RAFT server: one state machine per member, advanced by [raft_step] inside a single tick that consumes every input the protocol reacts to (client requests, both timers, and all intra-cluster traffic over one channel).

See raft for the input/timer contracts. The only feedback loop — a member’s outbound messages reaching other members’ inputs — passes through the network demux, which is an asynchronous boundary, so no in-tick cycle exists and no tick-deferral plumbing is needed.
