Trait KeyedSingletonSnapshotBound

pub trait KeyedSingletonSnapshotBound: KeyedSingletonBound + Sealed { }
Expand description

Marker trait for the KeyedSingletonBound types that support KeyedSingleton::snapshot: those whose entries may change over time (Unbounded, MonotonicKeys, MonotonicValue) and fully Bounded keyed singletons (whose complete contents are observed on every tick).

BoundedValue is excluded: each of its entries is final once it appears, so it is windowed into a tick with KeyedSingleton::batch, which observes just the new entries.

Dyn Compatibility§

This trait is not dyn compatible.

In older versions of Rust, dyn compatibility was called "object safety".
