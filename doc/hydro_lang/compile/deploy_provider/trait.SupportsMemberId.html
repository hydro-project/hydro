pub trait SupportsMemberId<Id> { }
Available on crate feature build only.
Expand description

A deployment backend that can run clusters whose member IDs have type Id. Each backend’s generated code works with particular ID types. Hydro Deploy and the simulator use u32, Docker, ECS, and Maelstrom use String, and the embedded backend accepts any type. with_cluster requires this trait, so a mismatch is a compile error.
