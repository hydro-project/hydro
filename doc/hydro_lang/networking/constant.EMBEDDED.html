A network channel implemented by the host of an embedded program, which chooses how messages travel: a network connection, an in-memory queue, or anything else that delivers them with the declared guarantees (for example EMBEDDED.exactly_once().total_order().fail_stop().name("messages")).

Items cross the channel unserialized: the generated channel ends carry the raw element type, and the host encodes it if its transport needs to. The program names only the guarantees, not a transport, so it is only supported by the embedded deployment backend and the Hydro simulator (which carries the raw values in memory); other backends use TCP or UDP.
