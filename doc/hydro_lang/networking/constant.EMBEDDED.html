A network channel implemented by the host of an embedded program, which chooses how messages travel: a network connection, an in-memory queue, or anything else. The program declares, for each anomaly, whether the host’s channel may introduce it, and the received stream is weakened by each one it may:

  • reordering: never_reorders or may_reorder;
  • duplication: never_duplicates or may_duplicate;
  • loss: never_drops, may_drop, or may_delay_forever.

Each axis must be declared (for example EMBEDDED.may_reorder().never_duplicates().never_drops().name("messages")). The never_* declarations hold as long as the channel remains live.

Items cross the channel unserialized: the generated channel ends carry the raw element type, and the host encodes it if its transport needs to. The program names only the anomalies, not a transport, so it is only supported by the embedded deployment backend and the Hydro simulator (which carries the raw values in memory); other backends use TCP or UDP.
